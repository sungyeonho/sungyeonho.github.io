## 1. 게임 전체 소개 {: #s1 }

AETHERFALL(에테르폴)은 하늘에서 떨어진 세계의 파편 위에서 장비가 곧 직업이 되는 언리얼 엔진 5 기반 PC 오픈월드 MMORPG다. 목표는 "스크린샷 한 장으로 팔리는 그래픽"과 "10년 운영 가능한 유저 경제"를 동시에 갖추는 것이다.

### 1.1 제목과 브랜드 콘셉트

| 항목 | 내용 |
|---|---|
| 정식 제목 | AETHERFALL: 에테르폴 |
| 태그라인 | "하늘이 무너진 날, 세계는 다시 쓰였다" |
| 장르 | 하이 판타지 오픈월드 샌드박스 MMORPG (액션 논타깃 전투) |
| 플랫폼 | PC(Steam·자체 런처) 우선, 콘솔은 출시 2년 차 검토 |
| 아트 톤 | 페인터리 리얼리즘: 실사 질감 + 과장된 색과 빛 (유지보수·성능·식별성의 균형) |

### 1.2 핵심 게임 플레이 루프

1. **장비를 착용한다** — 무기 2세트 + 방어구 3부위가 곧 스킬 구성이다.
2. **위험도가 다른 지역에서 사냥·채집한다** — 위험할수록 보상과 손실이 함께 커진다.
3. **재료를 팔거나 직접 제작한다** — 거의 모든 장비는 유저가 만든다.
4. **장비는 소모된다** — 내구도 파괴, 위험 지역 사망 시 드롭으로 수요가 계속 생긴다.
5. **길드로 영지를 점령하고 세금·자원을 얻는다** — 다시 더 좋은 장비로 이어진다.

### 1.3 차별화 요소 (6개)

| # | 시스템 | 내용 | 왜 다른가 |
|---|---|---|---|
| 1 | 에테르 공명(Resonance) | 두 무기 세트를 교체할 때 특정 조합이면 '공명 궁극기'가 해금된다. 예: 화염 지팡이 → 대검 교체 시 "작열참" | 장비 조합 자체가 숨겨진 스킬 트리가 된다 |
| 2 | 레이라인 기상 | 지역마다 마나 기상(화염풍·서리장막·뇌우·성광·흑월)이 4~6시간 주기로 바뀌고 해당 원소 스킬이 +10% / 상극 원소 -10%(PvP는 ±5%). 권역마다 순환 순서가 달라 한 원소가 서버 전체에서 동시에 우세하지 않는다 | 날씨가 그래픽 연출이자 전술 변수 |
| 3 | 낙하 파편(Fallen Shard) | 하늘섬 조각이 주 3회 실제로 떨어져 지형을 바꾸고, 희귀 자원·보스가 있는 임시 분쟁 거점이 된다 | 월드가 고정 맵이 아니라 계속 변한다 |
| 4 | 각인 장비(Inscription) | 무기 사용 기록(처치 수·보스 처치·제작자 서명)이 쌓이면 외형·이펙트가 3단계로 진화하고 거래 시 이력이 남는다 | 같은 무기도 '역사'가 가치가 된다 |
| 5 | 영지 생태계 | 길드 영지의 채집·사냥 강도에 따라 자원이 고갈되거나, 방치 시 위험 몬스터가 번식한다 | 영지 운영이 단순 점령이 아닌 관리 게임 |
| 6 | 에테르 화물선 | 지역별 분리 시장 사이를 길드 비행선으로 운송하고, 항로에서 공중 습격이 일어난다 | 물류·PvP·경제가 하나의 콘텐츠로 연결 |

|---|---|---|---|

| 경제·제작 플레이어 | 20% | 시장 장악, 제작 명성 | 각인 장비, 지역 시세, 화물선 |

### 1.5 장기 운영 방향

- **12주 단위 시즌제**: 시즌마다 영지 지도 리셋 일부, 신규 무기 스킬 2~4종, 낙하 파편 테마 교체.
- **연 1회 대형 확장**: 새 대륙 1개 + 신규 무기 계열 1종.
- **수익 모델**: 바이 투 플레이(기본 패키지) + 선택 구독 '에테르 서약'(편의 기능) + 외형 상점. 전투 능력치 판매는 금지한다.

## 2. 세계관 및 스토리 {: #s2 }

무대는 세계 '베일라스(Veilas)'다. 하늘에 떠 있던 신들의 대륙 '엘리움'이 부서져 떨어진 지 300년, 파편에서 흘러나온 에테르가 땅과 생명과 마법을 바꾸고 있다. 플레이어는 주인 없는 땅을 개척하는 '각인자(Inscribed)'다.

### 2.1 연표

| 시대 | 사건 | 게임 내 흔적 |
|---|---|---|
| 천공기 | 엘리움의 에테르 기술 문명이 지상 종족을 다스림 | 고대 신전, 부유 제단 |
| 대낙하(0년) | 엘리움의 핵 '아스트랄 엔진' 폭주, 대륙 붕괴 | 거대 크레이터, 균열지 |
| 재의 세기(0~120년) | 에테르 오염으로 변이 몬스터 출현, 종족 전쟁 | 폐허 요새, 변이체 |
| 맹약기(120~280년) | 4종족이 왕도 솔렌홀드에서 '파열환 조약' 체결 | 중앙 도시, 조약석 |
| 현재(300년) | 하늘에 남은 파편이 다시 떨어지기 시작. 조약은 개척자들에게 무주지 개방 | 낙하 파편 이벤트, 길드 영지 |

### 2.2 메인 스토리 아크

1. **각성** — 플레이어는 낙하 파편에 스친 뒤 몸에 파열환 문양이 새겨진다. 문양은 장비의 힘을 읽고 끌어내는 능력(=장비 기반 직업의 설정적 근거)이다.
2. **파편의 목소리** — 각 지역의 고대 신전에서 아스트랄 엔진의 파편 5개를 찾는다.
3. **심연의 교단** — 엔진을 재가동해 하늘을 되찾으려는 교단 '공허의 합창'과 대립한다.
4. **시즌 스토리** — 이후 이야기는 12주 시즌마다 월드 이벤트로 진행되며, 서버 전체의 행동(파편 점령률 등)이 다음 장을 바꾼다.

스토리는 선택 콘텐츠다. 메인 아크는 약 15시간이며, 완료 여부와 관계없이 샌드박스 콘텐츠에 바로 들어갈 수 있다.

### 2.3 종족

종족은 외형과 소폭의 패시브만 다르다. 전투 역할을 종족이 제한하지 않는다(패시브는 전투·경제 효과 없이 편의 효과만 주며, 4종족의 가치를 같게 맞춘다).

| 종족 | 설정 | 외형 포인트 | 종족 패시브(편의) | 수도 |
|---|---|---|---|---|
| 아스테른(인간) | 낙하 이후 가장 넓게 퍼진 개척 민족. 제도와 상업에 능함 | 다양한 체형·피부색, 문양 문신 | 도시 귀환 대기 시간 -10% | 솔렌홀드 |
| 엘라리 | 에테르에 감응해 피부가 은은히 빛나는 요정계 종족 | 반투명 귀 끝, 발광 문신, 길쭉한 사지 | 자원 노드 탐지 반경 +20m | 실바르 대삼림 수해성 |
| 드라고르 | 용의 피가 섞인 반용족. 화산대에서 단조와 채굴을 장악 | 비늘 피부, 뿔, 큰 체격 | 낙하 피해 -20% | 이그니스 대장간 |
| 녹스 | 심연에서 올라온 그림자 망명자. 어둠에서 살아남은 통찰력 | 회청색 피부, 빛을 반사하는 눈, 그림자 문양 | 어둠 속 시야 거리 +15% | 심연 입구 도시 녹테르 |

### 2.4 대륙과 지역

첫 출시 월드는 대륙 '아스테리아' 하나다. 약 64km² 규모(8개 권역, 권역당 평균 약 8km². 고대 신전 지대는 약 4km²의 던전 중심 소형 권역)로 시작하고 확장팩마다 대륙을 추가한다.

| 권역 | 테마 | 위험 등급 | 대표 장소 |
|---|---|---|---|
| 솔렌 평원 | 왕도와 구릉, 중세 도시 | 성역~개척지 | 왕도 솔렌홀드, 백석성 |
| 실바르 대삼림 | 거대 수목과 협곡, 폭포 | 개척지~분쟁지 | 수해성 엘류린, 안개 협곡 |
| 이그니스 대장간 | 활화산, 용암강, 흑요석 요새 | 분쟁지~혈전지 | 단조 도시 카르도르, 잿빛 분화구 |
| 프로스트베일 | 눈 덮인 설산, 빙하, 오로라 | 분쟁지~혈전지 | 빙궁 힐드리엘, 부서진 하늘다리 |
| 아르카나 균열지 | 에테르가 분출하는 빛나는 마법 대지, 부유 바위 | 혈전지 | 대낙하 크레이터, 부유 제단 |
| 고대 신전 지대 | 엘리움 유적, 거상, 부서진 회랑 | 개척지~분쟁지(신전 던전 4곳의 입구) | 신전 네 곳 |
| 망각의 심연 | 대륙 밑 지하 세계, 폐광과 우주동굴 | 분쟁지(1~3층)~공허지(4~5층) | 입구 도시 녹테르, 심연 층 1~5 |
| 하늘섬 군도 | 하늘에 남은 파편 섬들, 에테르 화물선으로만 접근 | 혈전지 | 낙하 파편 예비 섬 |

## 3. 그래픽 디자인 가이드 {: #s3 }

아트 방향은 '페인터리 리얼리즘'이다. PBR 실사 재질 위에 색을 15~20% 과장하고, 빛과 안개로 깊이를 만든다. 판정 기준은 "최고 설정 스크린샷은 트레일러급, 최저 설정도 모바일처럼 보이지 않게"다.

|---|---|---|---|

| 거대 성·요새(백석성, 흑요석 요새) | 절벽 위 다층 성곽, 길드 문장 깃발 | 회색 석재 + 길드 색 | Nanite 고폴리 석재, 길드 문장 = 데칼 + 머티리얼 파라미터 |
| 숲과 계곡(실바르) | 100m 거목, 빛줄기, 폭포 안개, 반딧불이 | 에메랄드·황록·청록 | Nanite Foliage(지원 범위 검증), 바람 버텍스 애니메이션, 볼류메트릭 포그 빛줄기 |
| 화산·용암(이그니스) | 흐르는 용암강, 불마루 하늘, 재가 내리는 평원 | 검정·주황·진홍 | 플로우맵 용암 셰이더 + 이미시브, 히트 디스토션, GPU 재 파티클 |
| 설산(프로스트베일) | 눈보라, 빙하 크레바스, 오로라 밤하늘 | 백·빙청·오로라 녹 | 런타임 가상 텍스처(RVT)로 발자국, 서브서피스 얼음 재질 |
| 고대 유적·신전 | 부서진 거상, 공중에 멈춘 파편, 빛나는 룬 | 모래색·청록 발광 | 이미시브 룬 마스크, 데칼 노후화, 아트용 레벨 인스턴스 |
| 어두운 지하 던전 | 횃불만의 어둠, 발광 버섯, 우주적 지하 호수 | 검정·남보라·청록 포인트 | Lumen 암부 품질 튜닝, 짧은 반경 동적 조명 다수 + 조명 예산 관리 |
| 빛나는 마법 지역(아르카나) | 부유 바위, 에테르 폭포가 거꾸로 흐름, 수정 숲 | 청록·자주·금 | 나이아가라 리본·메시 파티클, 반투명 굴절 수정(저사양은 불투명 대체) |

**날씨와 시간**: 게임 내 1일 = 실제 2시간. 하늘은 Sky Atmosphere + Volumetric Cloud로 구성하고, 날씨(맑음·비·눈·안개·모래폭풍·재)와 레이라인 기상(원소별 하늘 색·내리는 파티클)을 서버가 지역 단위로 방송해 모든 클라이언트가 같은 하늘을 본다. 비가 오면 재질에 젖음(Wetness) 파라미터를 전역 적용한다.

### 3.3 캐릭터 그래픽

- **모델 예산**: 플레이어 캐릭터 LOD0 약 60~80k 삼각형(모듈 부위 합계), LOD1 50%, LOD2 25%, LOD3 10% + 원거리 임포스터. 보스는 150~300k.
- **모듈형 장비**: 머리·상의·장갑·하의·신발·망토·무기 7개 외형 슬롯(전투 능력 슬롯과는 별개, 4.1 참조). 같은 스켈레톤에 스킨드 메시를 교체하고, 실행 시 하나의 메시로 병합(Skeletal Mesh Merge)해 드로우콜을 줄인다.
- **갑옷 고유 디자인**: 방어구 계열 3종(천·가죽·판금) × 티어 8단계. 티어가 오를수록 실루엣이 커지고 장식·발광 디테일이 늘어 멀리서도 등급이 읽힌다.
- **무기 외형 변화**: 각인 1~3단계마다 텍스처 패턴 → 발광 룬 → 상시 오라 파티클 순으로 진화. 머티리얼 파라미터만 바꿔 추가 메시 비용이 없다.
- **물리**: 망토·로브 자락·머리카락은 Chaos Cloth. 본인 캐릭터 + 화면 내 가까운 8명만 풀 시뮬레이션, 나머지는 본 기반 간이 흔들림으로 자동 전환한다.
- **애니메이션**: 모션 캡처 + 키프레임 과장. 이동은 모션 매칭, 발 디디기는 IK, 상·하체 분리 블렌딩으로 이동 중 시전을 자연스럽게 한다.
- **개성 있는 전투 모션**: 무기 계열마다 전용 로코모션 세트(대기·달리기·회피)를 두고, 종족별로 체형 리타겟팅한다.

|---|---|---|---|

업스케일러는 TSR을 기본으로 하고 DLSS·FSR·XeSS를 선택지로 제공한다. 엔진 버전은 착수 시점 최신 안정 버전으로 고정하고, 실험 기능(예: Nanite 스킨드 메시·수목)은 1단계 기술 검증에서 통과한 것만 쓴다.

## 4. 캐릭터 및 장비 {: #s4 }

고정 직업은 없다. 캐릭터의 역할은 착용한 무기 2세트와 방어구 3부위가 결정하고, 성장은 '어떤 장비를 얼마나 썼는가'로 쌓인다.

### 4.1 장비 슬롯과 스킬 구성

| 전투 슬롯 | 전투 기능 | 대응 외형 슬롯 | 비고 |
|---|---|---|---|
| 주무기 A / B (2세트) | 기본 공격 + 액티브 3개(계열별 풀 6개 중 선택) | 무기 | 주무기 13종. 교체 쿨타임 8초, 교체 시 공명 판정 |
| 보조손(방패·마도서·횃불) | 액티브 1개(방어·유틸) | 무기(보조) | 한손 무기(한손검·도끼)를 든 세트에서만 착용 |
| 머리 | 액티브 1개(생존·정화) | 머리 | 천·가죽·판금별 스킬 풀이 다름 |
| 상의 | 액티브 1개(방어·저항) | 상의 | |
| 신발 | 액티브 1개(돌진·순간이동·질주) | 신발 | |
| 장갑 | 기본 방어력 + 부가 능력치 1종(공격 속도·시전 속도·치명타 확률 중 제작 시 결정) | 장갑 | 액티브 없음 |
| 하의 | 기본 방어력 + 부가 능력치 1종(최대 체력·상태이상 저항·이동 속도 중 제작 시 결정) | 하의 | 액티브 없음 |

외형 슬롯 7개는 '형상 변환'으로 다른 아이템의 외형을 덮어쓸 수 있다. 단, 무기 계열 실루엣과 스킬 장판은 바꿀 수 없다(PvP 가독성). 이렇게 나눠 외형과 전투 밸런스를 따로 관리한다.

핫바는 총 8칸(무기 3 + 보조 1 + 머리 1 + 상의 1 + 신발 1 + 공명 1)이다. 엔드게임까지 핫바 수는 늘지 않는다. 조합이 깊어질 뿐이다.

### 4.2 주무기 13종 + 보조손 방패

기획 요구의 14종은 주무기 13종과 보조손 방패 1종으로 나뉜다. 방패는 무기 슬롯이 아닌 보조손 슬롯에 끼며 숙련도는 따로 쌓는다. 한손 무기는 한손검·도끼, 나머지 11종은 양손이다. 고유 스킬의 상세 명세(모션·이펙트·수치)는 5장 스킬 표에 있다.

| 무기 | 역할·공격 방식 | 기본 공격 모션 | 대표 고유 스킬 | 특수 능력(패시브) | 장점 | 단점 |

### 4.4 성장 방식: 무기 숙련도 + 능력치는 장비에서

- **캐릭터 레벨은 없다.** 전투력은 장비 티어(T1~T8) × 품질 × 숙련도로 결정된다.
- **무기 숙련도**: 무기를 쓰면 해당 계열 숙련도(0~100)가 오른다. 20단위로 스킬 풀 해금, 높은 티어 착용 자격, 아이템 파워 +1~+100을 준다.
- **하위 특화**: 숙련도 60 이후 계열마다 특화 2갈래(예: 대검 = '처형자' 한방 / '강철벽' 방어) 중 하나를 고른다. 재선택은 은화로 가능(재화 소각처).
- **수평 성장**: 다른 무기 숙련도도 스킬 조합·공명 해금을 위해 병행하기를 유도. 매주 '수련 목표'로 직접 지정한 계열 1개만 숙련도 획득 +20%(선택형, 무기 조합과 무관).
- 방어구도 별도 숙련도를 갖는다(천·가죽·판금).
- **따라잡기**: 서버 상위 10% 숙련도 평균보다 낮은 계열은 숙련도 획득이 최대 +50%(격차에 비례해 줄어듦). 신규·복귀 유저의 격차를 줄인다.

### 5.2 피해 공식과 밸런스 원칙

<div class="formula">Damage = (WeaponAtk · C<sub>skill</sub> + F<sub>skill</sub>) · (1 + ΣB<sub>atk</sub>) · <span class="frac"><span>100</span><span>100 + Def · (1 − Pen)</span></span> · M<sub>elem</sub> · M<sub>crit</sub> · M<sub>mode</sub></div>

- C(계수)와 F(고정치)는 스킬 데이터에 있다. 아래 표의 '피해'는 C를 무기 공격력 대비 %로 적은 것이다.
- **M_elem(상성)**: 레이라인 기상 ±10%(PvP ±5%), 적 저항에 따라 0.75~1.25.
- **M_mode(모드 계수)**는 공식의 마지막 단계에서 딱 한 번 적용한다. 기본값은 PvE 1.0, PvP 피해 0.6 / 치유 0.7이다. 스킬 데이터에 `pvpOverride`가 있으면 기본값을 대체한다(곱하지 않는다). 스킬 표의 'PvP 대체 0.5'는 최종 PvP 계수가 0.5라는 뜻이다.
- **목표 TTK**(초기값, 테스트로 확정): 동급 1대1 8~12초, 소규모 집중 포화 5~7초, 대규모 집중 포화 4~6초. v0.1의 2~3초는 대응할 시간이 없어 상향했고, 50명·100명 전투 테스트에서 다시 잰다.
- **스킬 예산**: '초당 계수'(C÷쿨타임)를 역할별 기준치에 맞추고, CC·이동·보호막은 환산 가중치로 다른 예산을 대체한다(예: 1초 기절 = 계수 40% 상당).
- **밸런스 도구**: 시뮬레이터(스킬 데이터만으로 더미 DPS·TTK 계산) + 라이브 텔레메트리(무기별 승률·픽률).

### 5.5 VFX 파이프라인과 성능 예산

- Significance Manager로 화면 내 이펙트 수가 예산을 넘으면 거리·중요도 순으로 자동 단순화한다.
- 옵션: '타인 이펙트 밀도' 0~100%, '화면 흔들림' 끄기, '섬광 감소'(광과민성 보호).
- **가독성 규칙**: 적 장판 = 빨간 테두리, 아군 = 파랑/초록 테두리. 스킬 색이 장판 테두리를 덮어선 안 된다.
- 화면 전체 섬광은 초당 3회를 넘지 않게 하고, 출시 전 광과민성 점검 도구로 검사한다.
- 공용 머티리얼 함수: 디졸브, 프레넬, 굴절, UV 왜곡, '에테르 라인'(브랜드 문양 흐름). 새 스킬은 이 함수 조합으로 만들어 셰이더 수를 억제한다.
- **검수**: 모든 스킬은 '100명 동시 시전' 벤치마크 맵에서 GPU 비용을 측정해 예산 초과 시 병합하지 않는다(CI 자동화).

`pvpOverride`가 `null`이면 전역 PvP 계수(피해 0.6, 치유 0.7)를 쓰고, 값이 있으면 그 값으로 대체한다. 두 값을 곱하는 경로는 없다.

## 6. 오픈월드 {: #s6 }

월드는 위험 등급 5단계로 나뉘며, 위험이 클수록 자원 티어와 사망 손실이 함께 커진다. 이 위험-보상 기울기가 경제와 PvP를 움직이는 엔진이다.

### 6.1 위험 등급

| 등급 | 분류(기획 요구) | PvP | 사망 패널티 | 자원 티어 | 비중(면적) |
|---|---|---|---|---|---|
| <span class="zone z1">성역(청)</span> | 안전 지역 | 불가 | 내구도 -5% | T1~T3 | 15% |
| <span class="zone z2">개척지(녹)</span> | 일반 필드 | 양측 동의(결투 신청)만 | 내구도 -10% | T3~T5 | 30% |
| <span class="zone z3">분쟁지(황)</span> | 위험 지역, 심연 1~3층 | 자유 공격. 선공자는 10분 '추적자' 표시 | 내구도 -15%, 가방 자원 30% 드롭 | T4~T6 | 25% |
| <span class="zone z4">혈전지(적)</span> | 고위험 사냥 지역, 하늘섬 군도 | 자유 공격 | 가방 전량 드롭 + 착용 장비 부위별 25% 확률 드롭(나머지 내구도 -30%) | T5~T8 | 22% |
| <span class="zone z5">공허지(흑)</span> | 심연 4~5층만 | 자유 공격, 동맹 외 전원 적 | 가방·착용 장비 드롭. 단 '각인 보호' 1부위는 드롭 대신 내구도 -50%, 장비 보험 가입 시 드롭 장비 가치의 40%를 은화로 환급 | T7~T8 + 공허 자원 | 8% |

**안전장치(v0.2 추가)**:

- **장비 보험**: 도시에서 착용 장비 가치의 8%를 은화로 내고(소각) 가입한다. 한 번 사망하면 소멸하며, 혈전지·공허지에서 드롭된 장비 가치의 40%를 돌려준다.
- **초보자 보호**: 계정 생성 후 30일 또는 숙련도 합계 200 미만인 캐릭터는 분쟁지에서 가방 손실이 없다. 혈전지·공허지는 보호 대상이 아니며, 입장 전 '잃을 수 있는 것' 확인 창을 띄운다.
- 공허지의 최고 위험은 유지하되 한 번의 사망으로 모든 장비를 잃는 일은 막는다.

사망 시 드롭된 장비 일부는 파괴되어 사라진다(아이템 소각, 8장). 텔레포트는 도시 간만 가능하며, 분쟁지 이상에서는 소지품을 들고 텔레포트할 수 없다.

### 6.2 지역별 설계

| 지역 | 등급 | 고유 몬스터 | 자원 | 보상 특색 | 배경음악 | 환경 이펙트 |
|---|---|---|---|---|---|---|
| 솔렌 평원 | 성역~개척지 | 들늑대, 평원 거대두더지, 산적단 | 밀·목화, 구리, 참나무 | 초반 장비 재료, 농사 씨앗 | 현악 중심 목가적 오케스트라 | 바람에 흔들리는 밀밭, 나비, 빛내림 |
| 실바르 대삼림 | 개척지~분쟁지 | 이끼 트롤, 나무정령 '드루엘', 거대 거미 | 희귀 목재, 약초, 가죽 | 활·지팡이 재료 | 켈틱 하프·플루트, 새소리 | 빛줄기, 폭포 물보라, 반딧불이 |
| 고대 신전 지대 | 개척지~분쟁지 | 수호 골렘, 신전 망령 | 에테르 파편, 대리석 | 각인석, 룬 재료 | 합창 + 저음 드론, 종소리 | 부유 파편, 살아나는 룬 빛 |
| 이그니스 대장간 | 분쟁지~혈전지 | 용암 샐러맨더, 흑요석 골렘, 화산 와이번 | 철·미스릴 광석, 흑요석, 유황 | 중갑·대검 재료 | 저음 타악기 + 남성 합창 | 재 내림, 용암 분출, 열기 아지랑이 |
| 프로스트베일 | 분쟁지~혈전지 | 설원 예티, 빙령 마녀, 얼음 매머드 | 모피, 서리 결정, 백은 | 얼음·방한 장비 재료 | 고요한 피아노 + 여성 보컬 | 눈보라, 오로라, 발자국 |
| 아르카나 균열지 | 혈전지 | 마나 정령, 변이 마수, 균열 감시자 | 에테르 수정, 부유석 | 지팡이·공명 재료 | 신스 패드 + 아르페지오 하프 | 거꾸로 흐르는 폭포, 부유 바위, 오로라 커튼 |
| 망각의 심연 | 분쟁지(1~3층)~공허지(4~5층) | 심연 촉수, 공허 교단원, 눈먼 벌레 | 공허석, 발광 버섯, 심해 광물 | 최상위 재료, 암흑 계열 | 음산한 드론, 심장박동 퍼커션 | 포자 입자, 우주적 발광, 물방울 |
| 하늘섬 군도 | 혈전지 | 천공 기사 잔해, 폭풍 그리핀 | 천공 금속, 구름 실 | 최상위 재료, 외형 희귀품 | 바람 타악기 + 합창 | 실시간 구름 통과, 바람 줄기 |

BGM은 탐험·긴장·전투 3개 스템을 동시에 재생하고 전투 상태에 따라 볼륨을 섞어 전환하는 적응형 음악(MetaSounds 또는 Wwise)으로 구현한다.

### 6.4 영지 생태계·낙하 파편·화물선 규칙

| 시스템 | 규칙 |
|---|---|
| 영지 고갈도 D (0~100) | 채집 1회마다 노드 티어에 따라 +0.5~2, 시간당 -3 회복. D 50부터 수확량이 1포인트당 -1%(최대 -50%), D 90 이상인 노드는 24시간 휴면 |
| 영지 위협도 T (0~100) | 영지 안 몬스터 처치량이 기준치보다 적으면 시간당 +2, 많으면 -4. T 60 이상이면 정예 출현률 2배, T 90 이상이면 '번식 둥지' 이벤트(제거 시 보상, 방치 시 영지 시설 공격) |
| 생태계 공개 | D·T 추이를 길드 화면과 지도에 표시. 기준치는 데이터 테이블로 조정 |
| 낙하 파편 일정 | 주 3회, 시간대를 돌아가며 배치(예: 한국 서버 13시·20시·23시), 30분 전 예고 |
| 낙하 파편 보상 분산 | 참여자 개인 기여 보상 60%(1인 상한 있음) + 점령 길드 보상 40%. 같은 길드·동맹이 같은 주에 다시 점령하면 길드 보상이 회당 50%씩 줄어든다 |
| 화물선 격추 손실 | 화물의 40%는 약탈 가능한 드롭, 30%는 파괴(소멸), 30%는 잔해에 남아 10분간 소유 길드가 우선 회수 |
| 화물 보험 | 출항 시 화물 가치의 5%를 은화로 내고(소각) 가입, 격추 시 파괴분의 70%를 환급(약탈분은 제외) |

### 6.5 구현 구조

- **클라이언트**: World Partition으로 128m 셀 스트리밍, 원거리는 HLOD. 지역 간 로딩 화면 없이 이동한다.
- **서버**: 지역을 '존'(약 1~2km²) 단위 프로세스로 분할하고, 존 경계에서 서버 간 핸드오프한다(11장). 낙하 파편은 사전 제작된 파편 레벨 8종을 예약 슬롯 12곳에 스트리밍하는 방식으로 지형 변화를 연출한다.
- **데이터**: `ZoneDef`(등급·경계·BGM·기상 테이블), `SpawnTable`(몬스터 밀도·리스폰), `ResourceNodeDef`(티어·고갈·회복 속도), `WorldEventDef`(조건·보상)를 디자인 데이터로 두고, 서버만 스폰 권한을 갖는다.

## 7. 몬스터 및 보스 {: #s7 }

출시 콘텐츠는 던전 6유형, 보스 8종이다. 보스는 '읽을 수 있는 패턴 + 압도적 화면 연출'을 원칙으로 하고, 화려함이 패턴 가독성을 가리지 않게 한다.

### 7.1 던전 유형

| 유형 | 인원 | 구성 | 소요 | 특징 | 보상 |
|---|---|---|---|---|---|
| 일반 던전 | 1~3인 | 구간 3 + 보스 1 | 10~15분 | 입장 티어 T3~T6, 현재 지역 등급 규칙 적용 | 재료, 숙련도 |
| 파티 던전 | 5인(구성 자유) | 구간 4 + 중간 보스 2 + 최종 보스 | 25~35분 | 기믹이 위협 관리·회복·해제를 요구(7.5) | 보스 재료, 각인 가속 |
| 고난도 던전 | 5인 | 파티 던전 + 주간 변이(어픽스) 2종 + 시간 제한 | 30분 제한 | 단계 1~20, 시즌 랭킹 | 최상위 재료, 시즌 타이틀 |
| 숨겨진 던전 | 3~5인 | 퍼즐 + 보스 1 | 20분 | 입구 이동·발견형(6.3) | 희귀 외형, 보물 |
| 월드 보스 | 무제한(존 상한) | 오픈 필드 | 10~15분 | 정규화 기여도 보상(7.5), 혈전지에서는 보스 중 PvP | 월드 보스 재료, 탈것 확률 |
| 길드 레이드 | 20인 | 보스 4연속 | 60~90분 | 주 1회 보상, 길드 성장 포인트 | 전설 재료, 길드 장식 |

일반 몬스터는 지역당 4~6계열 × 일반/정예/우두머리 3등급이다. 정예는 접두어 속성(화염의, 분열하는, 강철의 등 12종)을 1개, 우두머리는 2개 갖는다.

### 7.2 보스 설계

| 보스 | 위치·콘텐츠 | 외형 | 핵심 패턴 | 등장·궁극기 연출 | 보상 |
|---|---|---|---|---|---|
| 뼈왕관 멧돼지 '그러크' | 솔렌 평원 필드 보스 | 6m 멧돼지, 등에 뼈 왕관 같은 엄니 | 돌진(직선 장판), 땅 파기 → 돌 투척, 50%에 새끼 소환 | 밀밭을 가르며 달려오는 등장, 궁극기 '평원 질주': 맵을 가로질러 3회 돌진 | 초반 가죽, 첫 보스 업적 |
| 아스트랄 감시자 | 고대 신전 일반 던전 | 10m 대리석 골렘, 등 뒤로 회전하는 룬 고리 3개 | 회전 레이저, 고리 분리 → 고리마다 원소 장판, 기둥 뒤 엄폐 | 석상이 깨어나며 눈에 빛, 궁극기 '천체 정렬': 고리 3개가 일렬로 서서 아레나 관통 빔 | 룬 재료, 각인석 |
| 이끼 거인 '그로스' | 실바르 파티 던전 '뿌리굴' | 20m 나무 거인, 몸에 이끼와 작은 빛의 꽃 | 뿌리 장판 연쇄, 포자 구름(해제 필요), 50%에 몸의 꽃이 피어 자기 치유 → 꽃 제거 필수 | 숲 전체에서 새떼가 날아오르고 언덕이 일어선다. 궁극기 '대삼림의 분노': 바닥 전체에서 뿌리가 솟고 안전지대 2곳 | 고대 목재, 지팡이 재료 |
| 빙결 여왕 '이세라' | 프로스트베일 고난도 던전 '힐드리엘 빙궁' | 얼음 왕관과 반투명 드레스, 뒤로 떠 있는 거울 6개 | 거울 분신(진짜 찾기), 빙결 토대 장판 퍼즐, 파티원 빙결 후 구출 | 왕좌의 얼음이 깨지며 기상. 궁극기 '절대영도': 아레나 전체가 얼고 색이 빠지며, 따뜻한 빛 기둥 3곳에서만 생존 | 얼음 지팡이 외형, 시즌 타이틀 |
| 흑요석 용 '카르다크스' | 이그니스 월드 보스 | 날개 편 폭 40m, 흑요석 비늘 사이로 용암이 흐름 | 직선 용암 브레스, 비행 폭격, 꼬리 휘두르기, 비늘 파괴 시 약점 노출 | 화산이 분화하며 용이 튀어나오고 지역 하늘이 붉게 물든다. 궁극기 '화산 각성': 15초간 운석 낙하 + 용암 범람 | 용 비늘(최상위 판금), 탈것 확률 |
| 천공 기사 '발타르' | 하늘섬 숨겨진 던전 | 반은 빛, 반은 그림자로 갈라진 몰락 기사 | 빛·그림자 자세 전환, 패링 가능 패턴(성공 시 그로기), 따라하는 분신 | 하늘에서 창을 꽂으며 착지. 궁극기 '일식': 화면이 반으로 갈라져 빛/어둠 영역이 뒤바뀜 | 천공 외형 세트 |
| 공허의 성가대장 '모르베인' | 심연 길드 레이드(20인) | 1페이즈 로브를 입은 사제 → 2페이즈 촉수가 솟은 30m 괴물 | 촉수 휩쓸기, 정신 지배(아군 하나를 조종), 합창 막기(사제들 차단), 3페이즈 바닥 붕괴 후 낙하 | 사제들의 합창이 커지며 바닥이 갈라진다. 궁극기 '공허 합창': 화면이 흑백으로 변하고 소리가 역재생, 빛나는 룬을 잡아야 생존 | 전설 재료, 길드 문장 장식 |
| 낙하의 심장 '아스트랄 엔진' | 아르카나 시즌 최종 월드 보스 | 크레이터 위에 떠 있는 100m 수정·기계 구조물, 고리가 공전 | 페이즈마다 원소 교체(화염→얼음→번개→암흑), 서버 전체 기여도 게이지 | 하늘의 파편들이 모여 구조물을 조립. 궁극기 '재낙하': 하늘 전체가 재생되듯 갈라지고 파편이 비처럼 내린다 | 시즌 전용 무기 외형, 스토리 진행 |

### 7.3 보스 연출 원칙

1. **등장(3~5초)**: 플레이어 카메라를 빼앗지 않고 보스 쪽으로 부드럽게 회전, 레터박스 + 보스 이름 타이틀 카드, 하늘·조명·BGM 전환. 첫 조우는 짧은 컷신(스킵 가능), 이후 1초 버전.
2. **궁극기 예고(2~3초)**: 보스 대사 + 화면 가장자리 원소색 비네트 + 전용 사운드 큐 + 아레나 장판. 화려함보다 먼저 보여야 할 것은 "어디로 피하는가"다.
3. **발동**: 아레나 조명 LUT 전환, 화면 흔들림은 거리 감쇠, 보스 궁극기 VFX 예산(5.5) 내에서 최대 연출.
4. **잔해**: 궁극기 후 아레나 모양이 바뀐 채 유지(균열·크레이터) — 다음 페이즈의 지형 변수.
5. PvP 가능 지역의 월드 보스는 컷신·카메라 회전 없이 환경 연출만 한다(공정성).

### 7.4 구현

- 보스 AI는 서버에서 돌아가는 페이즈 상태머신 + 패턴 덱(가중 랜덤, 같은 패턴 연속 금지, 쿨타임)이다. 일반 몬스터는 가벼운 유틸리티 AI로 서버 CPU를 아낀다.
- 연출은 클라이언트의 Level Sequence로 로컬 재생하고, 서버는 '연출 시작 시각 + 패턴 ID'만 방송해 모두가 같은 타이밍을 본다.
- 데이터 예: `BossDef { id, phases:[{hpBelow, patternDeck:[{patternId, weight, cooldown}], arenaState, music}], enrageTime, lootTable }`.

### 7.5 역할·보상 규칙과 보스 수치 명세

자유 장비 철학에 맞춰 던전은 역할을 강제하지 않고, 파티가 채워야 할 '최소 기여 조건'만 둔다.

- **역할 최소 조건**: 보스마다 위협 관리(보스 시선을 끄는 '도발 표식' 유지), 회복·보호막 총량, 해제(정화) 횟수 중 필요한 것을 명시한다. 머리·상의 액티브(정화·보호)로도 채울 수 있어 어떤 무기 조합이든 설계로 해결할 수 있다.
- **매칭**: 역할 선호 태그만 참고하고 구성을 강제하지 않는다.
- **월드 보스 기여도**: 피해·치유·보호막·피해 흡수·해제를 항목별 백분위로 정규화해 합산한다. 상위 30%는 같은 등급 보상, 30초 이상 전투 참여자는 기본 보상을 보장한다. 한 길드·동맹이 받는 희귀 보상은 전체의 40%가 상한이다.

**보스 수치 명세 예시 — 이끼 거인 '그로스'**(파티 던전, 5인 기준). 나머지 보스도 같은 양식으로 작성한다. 피해는 플레이어 최대 체력 대비 %다.

| 패턴 | 예고 | 판정 | 피해·효과 | 대응 | 주기·조건 |
|---|---|---|---|---|---|
| 뿌리 장판 연쇄 | 장판 1.5초 | 반경 3m 원 5개 순차 | 25% + 속박 1초 | 이동 | 12초 |
| 포자 구름 | 장판 2초 | 반경 6m, 8초 지속 | 초당 4% + 치유 감소 30% | 정화 또는 이탈 | 20초 |
| 꽃 개화 | 보스 대사 + 꽃 발광 | 꽃 4개(각 체력 = 보스의 3%) | 남은 꽃 1개당 보스 초당 0.5% 회복 | 원거리 집중 제거 | 보스 체력 50%에서 1회 |
| 대삼림의 분노(궁극기) | 3초, 화면 비네트 | 아레나 전체, 안전지대 2곳(반경 3m) | 80% | 안전지대로 이동 | 체력 30%·10% + 90초마다 |
| 광폭화 | 배경음악 전환 | 전체 | 보스 공격력 +100% | 제한 시간 내 처치 | 전투 8분 경과 |

보상: 고대 목재 3개 확정, 지팡이 재료 1~2개(드롭표 별도), 최초 처치 업적. 목표 클리어율은 최초 도전 30%, 파티 3회차 70%로 잡고 테스트로 조정한다.

## 8. 경제 및 제작 {: #s8 }

장비의 90% 이상은 플레이어가 만들고, 장비는 소모된다. 경제의 건강성은 '일일 은화 소각량 ÷ 생성량'을 0.9~1.05로 유지하는 것으로 판단한다.

### 8.1 생활 콘텐츠

| 활동 | 도구 | 산출물 | 주요 지역 | 특징 |
|---|---|---|---|---|
| 채집(약초·섬유) | 낫 | 약초, 목화·아마 | 평원·대삼림 | 물약·천 장비 재료 |
| 광물 채굴 | 곡괭이 | 광석, 보석 원석 | 대장간·설산·심연 | 판금·금속 무기 재료 |
| 벌목 | 도끼 | 원목 | 대삼림·신전 | 활·지팡이·건축 재료 |
| 낚시 | 낚싯대 + 미끼 | 어류, 희귀 잡동사니 | 강·호수·심연 호수 | 미니게임(장력 관리), 요리 재료 |
| 농사·목축 | 개인 농지·길드 영지 | 작물, 가축, 탈것 | 하우징 플롯 | 실시간 성장(22시간 주기), 로그아웃 중 진행 |
| 해체 | 무기 | 가죽, 뼈 | 전 지역 | 가죽 장비 재료 |

채집 활동도 숙련도(0~100)가 있고, 높을수록 높은 티어 노드를 채집하고 추가 수확 확률이 오른다. 자원 노드는 고갈·회복 속도를 가지며 길드 영지에서는 생태계 값(1.3 차별화 5, 6.4)에 따라 달라진다.

### 8.2 제작 흐름

1. **원자재 → 정제**(제련소·제재소·무두장·방직소). 하위 티어 정제품을 재료로 요구해 저티어 수요를 유지한다.
2. **정제품 → 장비 제작**(대장간·활공방·마도 작업대). 도시마다 특화 분야가 있다(예: 카르도르 = 대검·판금 재료 환급 +15%).
3. **품질 굴림**: 보통 / 좋음 / 우수 / 걸작 / 명작. 제작 숙련도가 높을수록 상위 품질 확률 상승(명작은 최대 1.5%).
4. **제작자 서명**이 아이템에 남고, 각인 진화 장비가 많이 나온 제작자는 시장에서 '명장' 배지를 얻는다.

### 8.3 아이템 등급

| 축 | 단계 | 결정 요인 | 효과 |
|---|---|---|---|
| 티어 | T1~T8 | 재료 티어 | 기본 아이템 파워(티어당 +100) · 외형 실루엣 |
| 품질 | 5단계 | 제작 굴림 | +0 / +10 / +20 / +50 / +100 파워 |
| 각인 | 0~3단계 | 사용 이력 + 각인석 | 외형·이펙트 진화 중심, 능력치는 단계당 +15 파워로 소폭 |

PvP 지역에서는 아이템 파워 1,100 이상을 소프트캡(초과분 50%만 반영)으로 눌러 장비 격차가 실력 격차를 압도하지 않게 한다.

### 8.4 거래와 시장

| 기능 | 방식 | 수수료·제한 |
|---|---|---|
| 지역 시장(거래소) | 도시 6곳에 분리된 매수·매도 주문장. 주문은 30일 유효 | 등록비 1.5% + 판매세 4%(구독 여부와 무관) |
| 경매장 | 각인 장비·외형 희귀품 같은 '유일한' 아이템을 48시간 경매 | 낙찰가의 5% |
| 유저 간 거래 | 1:1 거래창(양측 확인 2단계) | 성역·개척지만, 계정 생성 7일 미만 제한(작업장 대응) |
| 플레이어 상점 | 도시 플롯에 노점·가게, 제작 주문 접수 가능 | 주간 임대료(소각) |
| 지역별 시세 | 도시 간 자원 격차 → 운송으로 차익. 시세 그래프·거래량 공개 | 운송은 짐수레·탈것·길드 화물선 |
| 수리 | 도시 수리소 또는 수리 키트 | 은화 소각(아이템 가치의 일정 비율) |

통화는 은화(기본)와 에테르 결정(유료)이다. 에테르 결정은 플레이어 간 결정 거래소에서 은화와 교환되며, 외형·구독에만 쓰인다. 전투 장비를 직접 판매하지 않는다.

### 8.5 재화 공급과 소각

| 구분 | 항목 | 비중 목표 | 조절 레버 |
|---|---|---|---|
| 공급 | 몬스터 은화 드롭 | 생성량의 45% | 드롭량 계수(지역별) |
| 공급 | NPC 고정가 매입(전리품·남는 재료) | 30% | 매입가 |
| 공급 | 퀘스트·이벤트·영지 세금 | 25% | 보상표 |
| 소각 | 수리비 | 소각량의 30% | 수리 계수 |
| 소각 | 시장 등록비·판매세·경매 수수료 | 25% | 세율(범위 내) |
| 소각 | 제작·정제 수수료 | 15% | 시설 수수료 |
| 소각 | 텔레포트·학습 비용·특화 재선택 | 10% | 요금표 |
| 소각 | 길드 영지 유지비·노점 임대료 | 15% | 유지비 공식(영지 수 누진) |
| 소각 | 기타·예비: 장비 보험·화물 보험·공성 선포·우편 수수료 | 5% | 요율(운영 중 미세 조정용 예비 레버) |
| 아이템 소멸 | 내구도 0 파괴, 사망 드롭 일부 파괴, 소모품 | 제작량의 70~90% 수준 | 내구도 감소율, 파괴 확률 |

공급 항목 합계와 소각 항목 합계는 각각 100%다. 다만 비율을 맞추는 것만으로 경제가 안정되지는 않으므로 8.7의 지표를 함께 본다.

**운영 방법**: 경제 대시보드(총 통화량, 일일 생성·소각, 아이템별 생산·소멸, 도시별 가격 지수)를 매일 점검하고, 비율이 2주 연속 목표 범위를 벗어나면 위 레버를 패치로 조정한다. 상위 1% 계정의 부 집중도와 봇 의심 패턴을 별도 추적한다.

### 8.6 데이터 구조와 무결성

```sql
-- 통화는 복식 부기 원장: 모든 이동은 차변·대변 한 쌍
CREATE TABLE currency_ledger (
  tx_id      UUID, entry_no SMALLINT,
  account_id BIGINT,          -- 캐릭터 / 시스템 계정(소각·발행)
  currency   TEXT, amount BIGINT,  -- +입금 / -출금, tx별 합계 = 0
  reason     TEXT,          -- 'MARKET_SALE','REPAIR','MOB_DROP'...
  created_at TIMESTAMPTZ,
  PRIMARY KEY (tx_id, entry_no)
);

CREATE TABLE market_order (
  order_id BIGSERIAL PRIMARY KEY, market_id SMALLINT, side CHAR(1), -- 'B'|'S'
  def_id TEXT, quality SMALLINT, price BIGINT, qty INT, remaining INT,
  owner_char_id BIGINT, escrow_ref UUID, expires_at TIMESTAMPTZ
);
CREATE INDEX ON market_order (market_id, def_id, quality, side, price);
```

- 매도 주문 등록 시 아이템은 에스크로(컨테이너 = MARKET)로 이동하고, 체결은 단일 DB 트랜잭션 안에서 아이템 이동 + 원장 기록을 함께 확정한다.
- 아이템은 고유 UUID와 버전(낙관적 락)을 가져 같은 아이템의 동시 이동을 거부한다. 야간 배치가 '원장 합계 = 잔액'과 아이템 중복 UUID를 검사해 복사 버그를 조기에 잡는다.

**거래 무결성 설계(v0.2 추가)**. 아이템과 은화의 모든 이동은 캐릭터·경제 서비스가 하나의 거래 흐름으로 처리하며, 존 서버는 서비스가 커밋을 확정한 뒤에만 인벤토리에 반영한다.

| 위험 상황 | 처리 방식 |
|---|---|
| 네트워크 재전송으로 같은 거래가 두 번 도착 | 모든 거래에 고유 거래 ID(UUID). 서버는 처리 결과를 거래 ID로 저장하고, 같은 ID가 다시 오면 저장된 결과만 돌려준다(멱등성) |
| 같은 아이템에 대한 동시 거래 요청 | 아이템 행의 소유권 버전을 비교한 뒤 갱신(compare-and-set). 하나라도 실패하면 거래 전체 취소 |
| 거래 도중 서버 종료 | 아이템 이동·원장 기록·주문 상태를 한 DB 트랜잭션으로 커밋. 커밋 전 종료는 전체 롤백, 커밋 후 종료는 재접속 시 거래 ID로 결과를 다시 조회 |
| 존 서버와 서비스 간 불일치 | 존 서버는 아이템을 직접 쓰지 않는다. 서비스 이벤트는 아웃박스 테이블로 발행해 장애 뒤에도 유실 없이 전달 |
| 거래소와 인벤토리 불일치 | 에스크로 컨테이너 + 체결 기록 테이블. 야간 대사로 주문 잔량·에스크로·원장이 일치하는지 확인 |
| 서버 장애·롤백 | 로그 기반 시점 복구(PITR) + 15분 단위 체크포인트. 롤백 시 그 이후의 결제·거래 로그로 보상 처리 |
| 백업·복원 | 일일 전체 백업 + 지속 로그 보관, 월 1회 실제 복원 리허설 |
| 이상 거래 | 단시간 대량 이동이나 원장 불일치를 감지하면 해당 품목·계정의 거래를 자동 중지하고 관리자 검토 |

### 8.7 경제 감시 지표

| 지표 | 보는 것 | 경보 기준(초기값) |

## 9. PvP 및 길드 {: #s9 }

PvP는 1대1부터 측당 100명 영토전까지 5단계로 설계한다. 대규모 전투의 안정성은 '인원 상한 + 예약된 전쟁 시간 + 서버·클라이언트 양쪽의 LOD'로 확보한다.

### 9.1 PvP 모드

| 모드 | 규모 | 규칙 | 장비 손실 | 보상 |
|---|---|---|---|---|
| 결투 | 1대1 | 오픈월드 신청·수락 | 없음 | 없음(연습) |
| 랭크 투기장 | 1대1, 3대3 | 장비 정규화(티어 무관 동일 파워), Glicko-2 매칭 | 없음 | 시즌 등급·외형 |
| 파편 쟁탈전 | 10대10 | 낙하 파편 거점 3개 점령, 15분 | 없음 | 시즌 포인트, 재료 |
| 오픈월드 교전 | 자유 | 분쟁지 이상 지역 규칙(6.1) | 지역 등급별 | 상대 드롭품 |
| 화물선 습격 | 소·중규모 | 항로상 화물선에 승선·보딩 | 화물 일부 | 화물 |
| 영토전 | 측당 최대 100명 | 예약된 전쟁 시간대, 거점 3개 + 성채 코어 | 해당 지역 규칙 | 영지 소유권 |

### 9.2 영토 점령

1. **선포**: 공격 길드가 은화를 소각해 공성을 선포한다. 영지 소유 길드가 미리 지정한 전쟁 시간대(한국 서버 20~24시 중 1시간)에 맞춰 최소 48시간 뒤 개전한다.
2. **준비**: 양측은 공성 무기(공성추, 작살포 거치대)와 수리 자재를 제작·운송한다. 경제와 전쟁이 여기서 만난다.
3. **전투**: 60분 동안 거점 3개를 점령하면 성채 보호막이 꺼지고, 코어를 파괴하면 공격 측 승리. 시간 종료 시 방어 측 승리.
4. **보호**: 점령 후 72시간 재공성 금지. 길드당 영지 수가 늘수록 유지비가 누진적으로 오르고 방어 시간대가 겹쳐 거대 길드의 독점을 억제한다.

**참가자 규칙(v0.2 추가)**: 길드(동맹 합산)는 개전 24시간 전까지 최대 130명의 명단을 등록하고, 전장에는 동시에 100명까지 들어간다. 부활 대기 중인 인원은 대기 명단과 교체할 수 있다(교체당 30초 지연). 명단은 길드가 정한 방식(지휘관 지정 또는 신청 선착순)으로 정하며, 300명 길드의 나머지 인원은 같은 시간 열리는 보급로 습격·방어 임무에 참여해 기여할 수 있다.

### 9.3 길드 성장과 시설

길드 레벨은 1~20이며, 레이드·영지 운영·기부로 얻는 길드 경험치로 오른다. 레벨 혜택은 인원 상한(50→300), 시설 슬롯, 생활 보너스다. 전투 능력치 보너스는 주지 않는다. 동맹은 최대 3길드이며, 영토전 인원 상한은 동맹 합산이다.

| 시설 | 해금 | 기능 |
|---|---|---|
| 길드 홀 | Lv1 | 길드 관리, 전략 지도, 회의 테이블 |
| 길드 창고 | Lv2 | 권한별 탭, 입출고 로그 |
| 길드 공방 | Lv5 | 제작 수수료 할인, 공성 무기 제작 |
| 훈련장 | Lv7 | 허수아비 DPS 측정, 내부 모의전 |
| 화물선 도크 | Lv10 | 에테르 화물선 건조·수리(하늘섬 접근) |
| 길드 보스 제단 | Lv12 | 길드 전용 보스 소환(주 2회), 길드 성장 포인트 |
| 공명 연구소 | Lv15 | 공명 궁극기 외형 변형 연구(외형만) |

### 9.4 랭킹과 시즌 보상

| 랭킹 | 기준 | 시즌 보상 |
|---|---|---|
| 투기장 | Glicko-2 레이팅 | 등급별 칭호, 시즌 무기 오라, 상위 100명 전용 망토 |

## 10. UI/UX {: #s10 }

UI는 화려한 화면을 가리지 않는 '최소 HUD + 깊은 메뉴'가 원칙이다. 전투 중 화면의 70% 이상은 월드가 보여야 하고, 경제·제작 화면은 정보 밀도를 높여 스프레드시트 없이도 판단할 수 있게 한다.

### 10.1 전투 HUD

| 위치 | 요소 | 동작 |
|---|---|---|
| 하단 중앙 | 핫바 8칸, 체력·자원·스태미나 게이지, 무기 교체 아이콘, 공명 게이지 | 교체 후 공명 가능 시 핫바 테두리 발광 6초 |

| 상단 중앙 | 대상·보스 체력바, 보스 패턴 이름 표시 | 보스 궁극기 시전 바 강조 |
| 상단 우측 | 미니맵(지역 등급 색 테두리), 레이라인 기상 아이콘, 시간 | 등급 경계 진입 시 화면 중앙 경고 배너 |

| 캐릭터 주변 | 피해 숫자(크기 = 비중), 상태이상 아이콘 | 피해 숫자 밀도 옵션 |

### 10.3 편의·접근성

- **입력**: 키보드·마우스 기본, 게임패드 완전 지원(스킬 휠 + 소프트 락온). 모든 키 재설정 가능.
- 색각 보정 모드 3종, 장판 테두리 두께·패턴(빗금) 옵션.
- 섬광 감소, 화면 흔들림 끄기, 자막·보스 대사 텍스트 표시, UI 크기 80~150%.
- **신규 유저 안내**: 첫 2시간은 성역에서 무기 4종을 직접 써보는 튜토리얼, 위험 등급 진입 전 "잃을 수 있는 것" 요약 팝업.

### 10.4 구현

UE5 UMG + CommonUI(입력 장치 전환·포커스 관리)로 만들고, 데이터 바인딩은 MVVM(ViewModel) 패턴을 쓴다. 대형 목록(시장·인벤토리)은 가상화 리스트로 그린다. UI 문자열은 처음부터 로컬라이제이션 테이블(한국어 기준, 영어·일본어 확장)에 둔다.

| 1. 생존 | 적 장판·보스 궁극기 예고, 내 체력·스태미나, 위험 등급 경계 경고 | 항상 표시, 어떤 이펙트도 가리지 못함 |

| 3. 상황 | 미니맵, 피해 숫자, 레이라인 기상, 퀘스트 추적 | 전투 중 축소 또는 밀도 제한 |
| 4. 소셜·경제 | 채팅, 거래 알림, 시장 체결, 길드 공지 | 전투 중 보류 후 전투 종료 시 묶어서 표시 |

## 11. 기술 아키텍처 {: #s11 }

엔진은 언리얼 엔진 5, 게임 로직 서버는 클라이언트와 전투 코드를 공유하는 커스텀 C++ 존 서버, 백엔드는 Go 마이크로서비스 + PostgreSQL로 구성한다. 존 서버 방식은 Phase 1의 부하 테스트(V1·V2)로 확정한다. 아래 11.2는 정식 출시 시점의 목표 구조이며, 초기에는 11.5의 최소 구성으로 시작한다.

### 11.1 엔진 비교와 선택

| 기준 | Unreal Engine 5 | Unity 6 |
|---|---|---|
| 그래픽 | Lumen·Nanite·VSM·Niagara·MetaHuman 등 고품질 기능이 기본 탑재. 목표 비주얼에 가장 가까움 | HDRP로 고품질 가능하나 동급 결과에 더 많은 커스텀 작업 필요 |
| 성능 | 고사양 중심, 저사양 튜닝에 노력 필요. C++ 직접 최적화 | 가벼운 기본 부하, 저사양·모바일 유리. DOTS로 대량 엔티티 처리 |
| 멀티플레이 | 내장 복제·데디케이티드 서버·Iris. 세션형에 강하고 수백 명 MMO 존은 커스텀 서버가 일반적 | Netcode for GameObjects/Entities. MMO급은 마찬가지로 커스텀 서버 필요 |
| 개발 난이도 | C++ 숙련도 필요, 빌드·도구 무거움. 블루프린트로 기획·아트 자체 제작 용이 | C# 진입 장벽 낮음, 반복 속도 빠름 |
| 확장성 | 전체 소스 코드 공개, World Partition으로 대형 월드 | 소스 접근은 Enterprise, 대형 월드는 자체 구현 비중 큼 |
| 비용 | 게임은 제품당 누적 총매출 100만 달러 초과분에 5% 로열티. Epic Games Store 매출은 로열티 제외 | 매출·투자 20만 달러 초과 시 Pro 좌석당 연 2,310달러 |

**선택: Unreal Engine 5.** 최우선 목표인 그래픽·이펙트 품질에서 격차가 가장 크고, 어느 엔진이든 MMO 서버는 커스텀이라 멀티플레이 차이는 크지 않다. 로열티는 매출 발생 후에만 내므로 초기 현금 부담도 낮다. 엔진 버전은 착수 시점 최신 안정 버전(기획 시점 5.8)으로 고정하고 대형 업그레이드는 출시 전 1회로 제한한다. 라이선스 조건은 Unreal Engine 라이선스, Unity 가격 정책 기준이며 착수 시 재확인한다.

### 11.2 시스템 구성도

| 매치·지역 서버 | 월드 디렉터 서비스 + Kubernetes·Agones(게임 서버 플릿) | 필드 존은 상시, 던전·투기장·영토전은 요청 시 할당. 존 경계 30m 중첩 구간에서 2단계 권한 이전 |

| 캐릭터 저장 | 캐릭터 서비스(Go) + PostgreSQL | 존 서버가 30초마다 저장, 거래·제작·사망·존 이동은 즉시 트랜잭션. 아이템 이동은 서비스만 수행 |
| 계정 시스템 | 계정 서비스 + 결제 서비스 | 2단계 인증, 기기 등록, 구매 영수증 서버 검증, 캐릭터 슬롯·제재 이력 |
| 채팅 시스템 | Go 채팅 서비스 + NATS 발행/구독 | 채널: 지역·거래·파티·길드·동맹·귓속말. 금칙어 필터, 도배 제한, 신고·차단, 로그 보관 |

### 11.4 주요 흐름

로그인에서 필드 입장까지:

1. 클라이언트 → 인증 서비스: 플랫폼 토큰 검증, JWT 발급.
2. 클라이언트 → 캐릭터 서비스: 캐릭터 목록 조회·선택.
3. 월드 디렉터: 마지막 위치의 존을 찾고 게이트웨이 주소와 입장 티켓 발급.
4. 클라이언트 → 게이트웨이 → 존 서버: 티켓 검증 후 캐릭터 상태 로드, 주변 엔티티 스냅샷 전송.
5. 존 경계 도달: 인접 존이 상태를 미리 받고, 클라이언트는 동일 게이트웨이 연결을 유지한 채 권한만 이전(로딩 없음).

**개발 운영 환경**: Perforce(에셋) + Git(서버·도구), 빌드 팜(야간 클라·서버 빌드 + 자동 테스트 + 성능 벤치), 환경 4종(개발·QA·스테이징·라이브). 초기 서비스 지역은 한국(서울 리전) 1개.

### 11.5 기술 스택 단계적 도입

처음에는 C++ 존 서버, 단일 Go 백엔드, PostgreSQL만으로 시작하고 나머지는 실제 병목이 확인될 때 넣는다. 초기 인프라 유지보수에 인력을 빼앗기지 않기 위해서다.

| 기술 | 도입 시점 | 도입 전 대안 | 도입 조건 |
|---|---|---|---|
| UE5 클라이언트, C++ 존 서버, PostgreSQL | Phase 1 | 없음 | 처음부터 |
| Go 백엔드(단일 서비스) | Phase 1 | 없음 | 인증·캐릭터·아이템을 한 서비스 안 모듈로 시작 |
| Perforce(에셋) + Git(코드) | Phase 1 | 없음 | 처음부터 |
| Prometheus·Grafana | Phase 1 | 없음 | V1부터 틱 시간 측정이 필요 |
| Redis | Phase 3 | PostgreSQL 세션 테이블 | 로그인·랭킹 조회가 DB 병목이 될 때 |
| 서비스 분리(캐릭터·경제·길드·채팅) | Phase 3~4 | 단일 서비스 안 모듈 | 담당 팀·배포 주기가 갈라질 때 |
| NATS | Phase 3~4 | DB 아웃박스 + 직접 호출 | 서비스가 둘 이상으로 나뉜 뒤 |
| ClickHouse | Phase 4 | PostgreSQL 로그 테이블·파일 | 로그가 하루 수천만 건을 넘을 때 |
| OpenTelemetry·Loki | Phase 4 | 구조화 로그 파일 | 서비스 간 추적이 필요할 때 |
| Kubernetes·Agones | Phase 5 | 고정 가상 서버 + 배치 스크립트 | 인스턴스 서버 수요 변동이 커질 때 |

## 12. 개발 인력 및 예산 {: #s12 }

예산은 한 번에 확보하지 않고 게이트마다 다음 단계 자금을 연다. 첫 목표는 약 17억 원으로 '버티컬 슬라이스'(최종 품질의 대표 구역 1개 + 무기 2종 + 보스 1종 + 50명 전투, 100명은 별도 기술 검증)를 만들어 투자·퍼블리셔를 설득하는 것이다.

**버티컬 슬라이스 범위(v0.2 축소)**. 10명·18개월로 모든 콘텐츠를 동시에 완성하려 하지 않고, '적은 콘텐츠를 최종 품질로' 만든다.

|---|---|---|

| 무기 | 4종 | 2종(대검·화염 지팡이, 공명 '작열참' 1종) |

## 13. 개발 일정 {: #s13 }

출시까지 66개월(5.5년)이다. v0.2는 기획 요구의 12단계를 6개 Phase로 묶어, 핵심 기술과 서버 검증을 콘텐츠 확장보다 먼저 끝낸다. 게이트는 G0(M8, 50명 전투 V2), GA(M18, 버티컬 슬라이스), GB(M48, 유료 얼리 액세스) 3개다. Phase는 겹쳐 진행하고, M은 착수 후 개월 수다.

<!--TIMELINE-->

| Phase | 기간 | 인력 | 난이도 | 산출물 | 포함 단계(기획 요구 12단계) | 통과 기준 |
|---|---|---|---|---|---|---|
| 0. 사전 기술 데모 | 착수 전 3개월 | 3 | 중 | 무기 1종, 봇 20기 전투, UE5 클라이언트와 C++ 서버 연결 | 1 일부 | 서버 권위 판정 동작, 자금 조달 자료 |
| 1. 핵심 기술 검증 | M1~M8 | 6~8 | 상 | 아트 바이블·그래픽 기반, 이동·카메라, 무기 2종, 서버 권위 전투, V1·V2 | 1, 2, 3 | G0: V2(50명) 통과, 권장 사양 60fps |
| 2. 게임 핵심 시스템 | M7~M18 | 10 | 최상 | 장비 교체·공명 1종, 숙련도, 몬스터 AI, 보스 1종, 인벤토리·아이템 데이터, 대표 구역 1개(최종 품질), V3 | 4, 5, 6 일부 | GA: 버티컬 슬라이스 시연, 투자 확보 |
| 3. 온라인 게임 기반 | M19~M30 | 15~20 | 최상 | 로그인·캐릭터 서비스, 존 서버·핸드오프, 파티·길드, 채팅, 거래 무결성(8.6), V4·V5 | 7 | V5 통과, 복사 버그 감사 0건 |
| 4. 경제와 월드 | M24~M40 | 20~30 | 상 | 채집·제작, 거래소·지역 시장, 지역 2~4개, 필드 이벤트, 경제 대시보드 | 6, 8 | 경제 시뮬 90일 동안 8.7 지표 정상 |
| 5. 대규모 콘텐츠 | M30~M46 | 30~35 | 상 | 주무기 13종 + 방패로 확장, 영토전, 화물선, 월드 보스, 던전·레이드 | 4 확장, 9 | 콘텐츠별 플레이테스트 통과 |
| 6. 출시 준비 | M40~M66 | 35→80 | 상 | 부하·보안·경제 감사(M40~M42), CBT 1(M42), CBT 2(M45), 안정화·출시 준비(M46~M48), 유료 얼리 액세스(M48), 얼리 액세스 운영·정식 출시 준비(M49~M66), 정식 출시(M66) | 10, 11, 12 | GB: D30 리텐션 12% 이상·가용성 99.5%, 출시 체크리스트 통과 |

게이트를 통과하지 못하면 일정을 미루기 전에 범위를 줄인다(예: 출시 지역 8→6, 주무기 13→9, 영토전 측당 100→60명). 그래픽·이펙트 품질 기준은 줄이지 않고, 콘텐츠의 양을 줄여 맞춘다.

## 15. 정식 출시 및 운영 계획 {: #s15 }

출시는 CBT → 유료 얼리 액세스(M48) → 정식 출시(M66) 순서다. 한국·아시아 서버로 시작하고, 정식 출시 때 북미·유럽 서버를 연다.

### 15.1 출시 단계

| 단계 | 대상 | 규모 | 목적 |
|---|---|---|---|
| CBT 1 (M42) | 초대 테스터 | 2,000명, 2주 | 전투·성장 검증, 서버 안정성 |
| CBT 2 (M45) | 신청자 | 10,000명, 3주 | 경제·영토전·부하 검증, 완료 후 데이터 초기화 |
| 얼리 액세스 (M48) | 유료 구매자 | 제한 없음 | 시즌 0, 라이브 운영 체계 확립 |
| 정식 출시 (M66) | 전체 | 한국·아시아·북미·유럽 | 대형 마케팅, 신규 서버 오픈 |

유통은 Steam + 자체 런처가 기본이다. Epic Games Store에 다른 스토어보다 늦지 않게 출시하면 UE 로열티가 5%에서 3.5%로 낮아지므로 동시 출시를 검토한다(Epic FAQ).

### 15.6 사업 지표와 손익분기점

패키지 판매는 한 번 걷는 매출이라, 월 운영비를 감당하려면 구독·외형 상점 같은 반복 매출이 중심이 되어야 한다. 아래 목표는 사업계획용 가정치이며, CBT 데이터로 다시 잡는다.

| 지표 | 정의 | 초기 목표(가정) |
|---|---|---|
| 얼리 액세스 판매량 | 첫 3개월 누적 구매 | 10만 개 |
| 구독 전환율 | 월간 활성 유저 중 구독자 비율 | 15% |
| ARPPU | 결제 유저 월평균 매출 | 1.5만 원 |
| 구매 전환율 | 위시리스트·체험판 이용자 중 구매자 비율 | CBT 데이터로 설정 |
| CAC | 유료 마케팅비 ÷ 신규 구매자 | 1만 원 이하 |
| LTV | 유저 1명의 누적 순매출 | CAC의 3배 이상 |
| 환불률 | 구매 후 환불 비율 | 10% 이하 |
| 서버 비용 | 동시접속 1명당 월 비용 | V4 부하 테스트 후 확정, 순매출의 15% 이하 |
| 손익분기점 | 월 순매출 ≥ 월 운영비 | 정식 출시 후 6개월 안 |

**손익분기 계산 예시(월 운영비 4억 원 가정)**. 순매출은 부가세 10%를 빼고, 패키지는 Steam 수수료 30%, 구독은 자체 결제 수수료 3%를 뺀 값이다(인건비·마케팅비는 운영비에 포함).

| 상품 | 가정 가격 | 1건당 순매출 | 월 4억에 필요한 수(총매출 기준) | 월 4억에 필요한 수(순매출 기준) |
|---|---|---|---|---|
| 패키지 | 39,000원 | 약 24,800원 | 약 10,300개 | 매달 신규 약 16,100개 |
| 구독 | 9,900원 | 약 8,700원 | 약 40,400명 | 약 45,800명 |

한 상품만으로는 어렵다. 예를 들어 구독 25,000명(약 2.2억) + 패키지 신규 판매 월 2,500개(약 0.6억) + 외형 상점·시즌 패스 순매출 약 1.2억을 합치면 월 4억에 닿는다. 구독을 Steam에서 팔면 수수료가 30%로 늘어 필요한 수가 더 커진다.

### 15.7 법률·운영 정책

| 분야 | 정책 |
|---|---|
| 게임물 등급 | 국내 등급 분류는 CBT 전에 일정 확보, 해외는 IARC 등 국가별 등급 |
| 확률형 상품 | 유료 확률형 상품은 팔지 않는다. 게임 내 주요 드롭 확률도 공개한다 |
| 현금 거래(RMT)·작업장 | 약관으로 현금 거래·계정 거래 금지, 거래 패턴 탐지(8.6), 신규 계정 7일 거래 제한, 경고 → 기간 정지 → 영구 정지의 단계적 제재, 이의 신청 절차 |
| 계정 도용 | 2단계 인증 권장, 고가 거래 시 재인증, 로그 기반 피해 복구 기준 |
| 미성년 이용자 보호 | 연령 확인, 미성년 결제 한도와 법정대리인 동의, 채팅 필터 기본 강화, 모르는 사람의 귓속말 차단 옵션, 신고·차단 우선 처리, 이용자 간 거래 제한 검토 |
| 개인정보 | 처리방침, 보유 기간, 탈퇴 시 삭제 절차, 로그 보관 기간 |
| 이용약관 | 계정 정지 사유, PvP 장비 손실은 보상 대상이 아님을 명시, 서버 롤백 시 보상 기준 |
| 결제·환불 | Steam·자체 런처 결제 경로별 환불 규칙 |
| 상표·저작권 | 'AETHERFALL' 선행 상표 조사·출원, 음악·모델·모션·성우 외주 계약에 저작권 귀속 명시 |
| 이용자 보호 | 신고·제재·분쟁 처리 절차와 처리 기한 |

이 표는 점검 목록이며 법적 판단이 아니다. 출시 국가별 법률 검토가 필요하다.
